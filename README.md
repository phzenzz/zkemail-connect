# zkEmail Solana Email Wallet

Send SPL tokens to an email address; the recipient claims them by replying to the relay
email with `Subject: <their Solana base58 address>`. The reply is verified with a
zkEmail Groth16 proof (DKIM signature checked in-circuit) and verified on-chain —
the recipient needs nothing but the email thread.

## Layout

- `circuits/` — Circom claim circuit (DKIM verify, To-presence, subject-address regexes), TS email loader / proving pipeline, jest tests
- `onchain/` — Anchor program `email-wallet`: `create_escrow` / `claim` / `sweep_inbox` + DKIM registry
- `prover/` — dockerized rapidsnark proving server (`POST /prove`)
- `e2e/` — end-to-end runner (real `.eml` → prover container → localnet claim)
- `docs/` — plan / requirement docs

## Prerequisites

node 20+, circom 2.1.6, anchor-cli 0.32.1 (via `avm`), solana CLI 2.2+, docker.
Test fixtures are real exported emails: see `circuits/testdata/emails/README.md` —
DKIM freshness is 48h, so expired `.eml` files must be re-exported before testing.
`npm install` requires GitHub SSH access (a transitive `snarkjs` dep resolves via
`git+ssh://git@github.com/...` in `package-lock.json`); if SSH to GitHub is not
available, add an npm `overrides` entry for that package instead.
`initialize_registry` is first-mover: the first caller becomes the registry
authority, so the program deploy and registry initialization must happen in the
same batch before any public use.

## Build & test (from repo root)

```bash
npm install && (cd circuits && npm install)
bash circuits/scripts/compile.sh     # circuit compile + constraint count (~10 min)
bash circuits/scripts/setup.sh       # trusted setup; skips the 4.8GB ptau download if build/pot22_final.ptau exists
(cd circuits && node scripts/gen-vk-rust.mjs)   # -> build/verifying_key.rs (proof fixtures are generated by the anchor tests via scripts/prove-for.ts)
cp circuits/build/verifying_key.rs onchain/programs/email-wallet/src/verifying_key.rs
(cd circuits && npm test)            # 20 circuit tests (needs fresh .eml, see above)
export PATH="$HOME/.avm/bin:$PATH"   # make anchor available
(cd onchain && anchor build && cargo test -p email-wallet && anchor test)
npm run prover:up && curl -s localhost:8080/health && npm run prover:down
npm run e2e                          # starts the prover container + validator itself
npx tsc --noEmit
```

> **DEV-ONLY — trusted setup & relay address**
> - `build/pot22_final.ptau` is the Hermez Powers-of-Tau ceremony ptau (power 22 of the
>   2^28 ceremony, Wayback snapshot), and `build/claim_final.zkey` carries a single local
>   dev contribution. Fine for dev/test; run a real multi-party contribution ceremony
>   before any testnet/mainnet deployment.
> - The relay email address lives in `circuits/relay.config.json` and is compiled into
>   the circuit's To-presence regex. Changing it requires
>   `bash circuits/scripts/rebuild.sh` (regex → compile → setup → vk → on-chain copy),
>   not just `compile.sh`.
